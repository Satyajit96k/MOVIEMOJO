# MovieMojo - Movie Ticket Booking System

MovieMojo is a modern web application for booking movie tickets. It provides a seamless experience for users to browse movies, select seats, and book tickets.

## Features

- Browse movies with detailed information
- View movie details including ratings, genres, and release dates
- Select theater and seats
- User-friendly interface
- Responsive design

## Tech Stack

### Frontend

- React
- TypeScript
- Material-UI
- Vite

### Backend

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- Python (v3.8 or higher)
- PostgreSQL

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/MovieMojo.git
cd MovieMojo
```

2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

3. Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
